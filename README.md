## 개요

이 레포지토리는 파인튜닝된 Qwen2.5-VL 모델을 기반으로 충남대학교 통합정보시스템(cnuit.cnu.ac.kr)을 자동으로 탐색하고 작업을 수행하는 Browser-Use 에이전트를 테스트하기 위한 임시 레포지토리입니다.

> ⚠️ **현재 모델 파인튜닝이 진행 중입니다. 임시(Temp) 레포지토리로 간주해주세요.**
